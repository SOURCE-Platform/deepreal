# Component references

Manufacturer datasheets and selected vendor geometry retained from earlier
feasibility research live here. They are evidence inputs, not the active
mechanical design. Blender remains the current geometry authority, and each
candidate must be rechecked before schematic or manufacturing freeze.

- `components/datasheets/` contains manufacturer documents and drawings.
- `components/cad/` contains selected vendor STEP/ZIP reference geometry.

The old project-authored FreeCAD models and scripts were intentionally removed.
Later production CAD should be reconstructed from the reviewed Blender concept
and verified component selections, not revived from the obsolete design.
